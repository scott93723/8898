# 8898

二手車買賣網站(油車與電動車)。純靜態、零依賴、零建置。

核心不是車輛列表 —— 那誰都會做 —— 而是一套**透明度徽章**機制:
每台車的資料完整度由前端逐項檢查、算分、公開顯示,
**沒通過的項目不隱藏,直接標成灰色刪除線的「未提供」**。

> ⚠ 站上目前是**示範資料**。16 台車、賣家名稱、統一編號、地址、驗車報告
> 全部虛構,不是實際待售車輛。

---

## 打開來看

**雙擊 `index.html`** 就能跑。資料走 `.js` 賦值檔而不是 `.json`,
就是為了讓 `file://` 直接可用(`fetch()` 讀 `.json` 會被 CORS 擋掉,整站會空白)。

要用伺服器跑也可以:

```bash
python -m http.server 8000
# 然後開 http://localhost:8000
```

沒有 `npm install`,沒有建置步驟,改完存檔重整就生效。

## 這站在解決什麼

二手車市場真正的問題不是「有騙子」,是**你查不出誰在騙**。
欄位空著就不顯示,買家看不出賣家沒回答;價格只有一個數字,
拆開來的費用要到現場才知道。在這種設計下,老實的賣家反而吃虧。

所以這個站只做一件事:把該交代的資料列成檢核表,由系統比對,
結果不管好壞一律公開。**「什麼都沒填」不再是一個安全的選項。**

### 六項透明度檢核

| 徽章 | 通過條件 | 擋的是什麼 |
|---|---|---|
| 明碼實價 | 費用明細加總 = 標示總價,且未標可議價 | 「電洽」、成交才冒出的代辦費 |
| 第三方驗車 | 有第三方報告,且在 180 天內 | 只有賣家一張嘴 |
| 里程可查 | 有里程,**且有寫出這個數字的依據** | 跳表 |
| 實拍達標 | 必拍角度全到齊,每張在 60 天內 | 型錄圖、網路盜圖 |
| 賣家實名 | 已驗證,且有統編或身分驗證 | 匿名賣家、一頁式詐騙 |
| 電池報告 | 油電與電車限定:有 SOH **且有依據** | 二手電車最貴的秘密 |

汽油車適用 5 項,油電與電車適用 6 項。

判定邏輯全部在 [`assets/core.js`](assets/core.js) 的 `scoreTransparency()`,
門檻常數(180 天、60 天、必拍角度)也在同一支的最上面。

### 幾個刻意的設計

- **誠實揭露不扣分。**`事故車 = true` 不會扣任何徽章;會扣分的是填 `null`,
  也就是不願回答。獎勵的是「講清楚」,不是「車況完美」。
- **未達標的車不下架。**照樣列出來,只是徽章是灰的。封鎖只會讓對方換帳號。
- **上架天數洗不掉。**`listedAt` 綁在車輛編號上,下架重上不重設。
- **價格變動公開。**`priceHistory` 畫成時間軸,擋先掛低價再加價。
- **無廣告版位、無推薦排序、無「限時」話術。**排序只看使用者選的條件。

## 檔案結構

```
8898/
├── index.html                首頁:搜尋 / 篩選 / 排序 / 車輛卡片
├── car/index.html            車輛詳情頁(?id=C0001)
├── how-it-works/index.html   防詐機制:六項徽章的判定規則與極限
├── sell/index.html           刊登規範與必拍角度
├── about/index.html          關於、技術做法、回報管道
├── assets/
│   ├── style.css             設計 token + 全站樣式
│   ├── core.js               政策常數、透明度計分、格式化、主題、佔位圖
│   ├── list.js               首頁篩選 / 排序 / 渲染
│   └── detail.js             詳情頁渲染
├── data/
│   ├── cars.js               全站唯一車輛資料來源
│   └── SCHEMA.md             欄位定義、必填規則、徽章門檻

```

沒有元件系統。頁首頁尾在各頁重複一份 HTML ——
這樣內容頁不依賴 JavaScript 也能完整顯示,代價是改導覽列要改五個地方。
頁數還少,這筆交易划算。

## 改資料

全部改 [`data/cars.js`](data/cars.js) 一個檔案,規格見
[`data/SCHEMA.md`](data/SCHEMA.md)。存檔重整就生效。

最重要的一條規矩:

> **缺的欄位不要刪掉,填 `null`。**
> 前端看到 `null` 會顯示成灰色的「未提供」;直接把欄位拿掉,
> 買家就看不出賣家在閃躲什麼 —— 那我們就跟想取代的東西沒兩樣了。

存檔前自己過一遍(或直接看瀏覽器 console,`core.js` 會自動檢查並警告):

1. `price.breakdown` 加總 = `price.total`
2. `priceHistory` 最後一筆 = `price.total`
3. `id` 沒撞號、`sellerId` 找得到人
4. `knownIssues` 有寫(沒缺陷填 `[]`,不要 `null`)

## 設計語言

刻意做成**資料表,不是廣告**。不用大圖橫幅、不用跑馬燈、不用漸層按鈕、
不堆陰影卡片、不用 emoji、不用圖示字型。髮絲線分隔、資訊密度高、
數字一律 `tabular-nums` 對齊。圖示全是 inline SVG(stroke-only)。

設計 token 在 `style.css` 的 `:root`,深淺色各一組,
`prefers-color-scheme` 自動 + 手動覆寫(`data-theme`),`<head>` 有防閃白腳本。

零外部依賴 —— 沒有 CDN、沒有 Google Fonts、沒有分析工具。
